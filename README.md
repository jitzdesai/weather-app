# Weather App

A simple Tkinter weather app that uses the Open-Meteo geocoding and forecast APIs.

## Run

```bash
./run_weather_app.sh
```

The launcher works from any terminal directory. On the first run, the app
uses `uv` to create or reuse `.venv`, install the declared dependencies, and
relaunch itself with Python 3.12. Install `uv` before running the app if it is
not already available.
