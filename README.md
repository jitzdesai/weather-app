# Weather App

A simple Tkinter weather app that uses the Open-Meteo geocoding and forecast APIs.

## Run

```bash
python3 weather_app.py
```

On the first run, the app uses `uv` to create or reuse `.venv`, install the
declared dependencies, and relaunch itself with Python 3.12. Install `uv`
before running the app if it is not already available.
